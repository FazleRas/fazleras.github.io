ACROBOT

code architecture

A GitHub Action that reviews pull request diffs with an LLM and leaves inline comments.

It runs on the Gemini free tier, so the limit is request quota, not money. Across 11 pull requests it found 2 planted bugs and 2 nobody planted, and the fixes merged.

  • Findings are schema-validated and line numbers checked against the parsed diff first. GitHub rejects a whole review over one bad anchor, so a made-up line costs one comment, not the run.
  • A cheap triage model filters diffs before the reviewer sees them: 800 requests a day against the reviewer's 18.
  • When the quota runs out it posts a partial review instead of failing CI.
  • 63 tests and an eval harness that replays recorded API responses, so scores stay comparable. Tokens, latency, and cost per stage go to the Actions summary.

The live repo it reviews is AlphaLab, below.

AlphaLab

live demo API docs code

A trading analytics platform for backtesting strategies, sweeping parameters, and scanning for setups.

18 REST endpoints and 12 React views behind JWT auth and Postgres row-level security. Most of the work went into showing when a good-looking backtest is just noise.

  • The backtester races four strategies against buy-and-hold and SPY on Sharpe ratio, CAGR, max drawdown, and win rate.
  • A sweep re-runs up to 121 RSI threshold pairs on a 70/30 chronological split, with a regression test that fails if any signal reads a future bar.
  • The heatmap doubles as an overfitting check: a green region means the edge holds, one green cell in a field of red means it was fit to noise. Out-of-sample validation then re-optimizes on the training window and runs the top combos blind.
  • The scanner derives nine signals across six combinable filters, with per-ticker fault isolation so one bad symbol can't kill a scan.
  • I moved the backend off managed hosting onto AWS EC2 behind Caddy with auto-renewing TLS, which got rid of the cold starts. Redis fronts the data feed and reports its own hit rate.

Metrics are single-ticker, with no transaction costs and a 0% risk-free rate, so a validated result is a place to start looking, not a prediction.

An interactive ASCII water simulator for the terminal. C++17, zero dependencies.

Click to splash, drive boats around, watch the wakes ripple.

  • A height field sized to your terminal, stepped by a two-buffer wave solver at 30 FPS. Each cell becomes half the sum of its neighbours minus its own last value, and that subtraction is what gives ripples momentum.
  • Raw-mode termios with SGR mouse reporting. Each frame renders into one string and goes out in a single write(), so it never tears.
  • A moving boat is a moving wave source, so its wake bunches ahead and stretches behind. The Doppler effect came out of the physics; I didn't draw it in.
