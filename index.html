ACROBOT

code architecture

A GitHub Action that reviews pull request diffs with an LLM and posts inline comments. It runs on the Gemini free tier, so the scarce resource is request quota rather than money, and that constraint shaped everything about the design.

Three rules run through the code. LLM output is untrusted input, so every finding is schema-validated and every line anchor is checked against the parsed diff before posting — GitHub rejects a review whole if one anchor is bad, so a hallucinated line number costs one finding instead of the run. Request budget is scarce, so diffs go through a cheap triage model carrying 44× the review model's daily quota (800 requests against 18), metered by a two-clock limiter that posts a partial review instead of failing CI when the budget runs out. And every run measures itself: per-stage tokens, latency, and cost land in the Actions summary.

It caught 2/2 deliberately planted bugs plus 2 unplanned edge cases across 11 pull requests on a live repo, with fixes merged. Backed by 63 tests and an eval harness that replays recorded API responses in CI, so scores stay reproducible against a nondeterministic model. Its own two false positives became the first eval cases.

The live repo it reviews is AlphaLab, below.

AlphaLab

live demo API docs code

A full-stack trading analytics platform: 18 REST endpoints and 12 React views behind JWT auth, per-user query scoping, and Postgres row-level security. I migrated the Dockerized backend from managed hosting to AWS EC2 behind a Caddy reverse proxy with auto-renewing TLS and security-group-scoped ports, which removed the free-tier cold starts that stalled first requests.

The backtester is a state machine that races four strategies against buy-and-hold and SPY on Sharpe ratio, CAGR, max drawdown, and win rate. A parameter sweep re-simulates up to 121 RSI threshold pairs per request with 70/30 chronological validation, guarded by a regression test that fails if any signal reads a future bar. The scanner derives nine signals across six combinable filters, with per-ticker fault isolation so one bad symbol can't kill a scan.

The sweep heatmap is really an overfitting check. A whole region of green cells points to a robust edge; a single green cell in a field of red is curve-fitting to noise. Out-of-sample validation then re-optimizes on the training window only and runs the top combos blind on data they never saw. Metrics stay single-ticker with no transaction costs and a 0% risk-free rate, so even a validated best is a starting point for analysis, not a prediction.

Smaller things I like: a two-point chart measurement tool for the move between any two points, backtests encoded in the query string so a link opens straight to that run, CSV export of trade history, pinned runs that reload in one click, and a Redis cache in front of the market data feed that fails open and reports its own hit rate.

watersim

code

An interactive ASCII water simulator for the terminal, written in C++17 with zero dependencies. Click to splash, drive boats around, watch the wakes ripple. 

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
~..--~~.~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~..~~
~-~~-~..~~-~~.....~~~~~~-~-~-~-~-~~~~~.....~~~-~..=~
~~~...~-=-~~......~.~.~.~.~.~.~.~.~.~.~.....~---~.~~
~.~~..~-=--~~~~~............>..............~--=-~.~~
~~~...~--=-~~~~~~..........................~-=--~.~~
~~..~~~----~~.......~.~.~.~.~.~.~.~.~.......~---~~~~
~~.~=-.~~~~....~~~~~~~~~~~~~~~~~~~~~~~~~....~~~..~~~
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The water is a height field sized to your terminal, stepped through a two-buffer wave solver at 30 FPS. Each cell becomes the sum of its four neighbours halved, minus its own previous value — that last term is what gives ripples momentum, so waves travel outward instead of diffusing in place, and damping lets the pond settle.

Input runs through raw-mode termios with SGR mouse reporting, and each frame is rendered into one string and pushed with a single write() syscall so it never tears. Because a moving boat is a moving wave source, its wake compresses ahead and stretches behind — a visible Doppler effect that fell out of the physics rather than being drawn in. A --demo flag runs the whole thing non-interactively as a smoke test.
