ACROBOT

code architecture

A GitHub Action that reviews pull request diffs with an LLM and leaves inline comments.

11 pull requests reviewed 4 real bugs found 63 tests Gemini free tier

  • Findings are schema-validated and every line number is checked against the parsed diff first. GitHub rejects a whole review over one bad anchor, so a made-up line costs one comment, not the run.
  • A cheap triage model gates diffs before the reviewer sees them, on its own quota pool: 800 requests a day against the reviewer's 18. When the quota runs out it posts a partial review instead of failing CI.
  • An eval harness replays recorded API responses against labeled cases, so recall and precision stay comparable across prompt changes. Tokens, latency, and cost per stage go to the Actions summary.

The live repo it reviews is AlphaLab, below.

AlphaLab

live demo API docs code

A trading analytics platform for backtesting strategies, sweeping parameters, and scanning for setups.

18 REST endpoints 12 React views JWT auth Postgres row-level security

  • The backtester races four strategies against buy-and-hold and SPY on Sharpe ratio, CAGR, max drawdown, and win rate, over a 70/30 chronological split. A regression test fails the build if any signal reads a future bar.
  • The heatmap doubles as an overfitting check. Out-of-sample validation then re-optimizes on the training window and runs the top combinations blind on history they never saw, with a verdict per combination.
  • Sweeps run as background jobs, so a refresh reattaches and a shared link opens straight to the progress. Redis fronts the data feed and reports its own hit rate.

Production runs on Render. Alongside it I built a self-managed AWS EC2 deployment of the same container behind Caddy, with auto-renewing Let's Encrypt TLS. Metrics are single-ticker, with no transaction costs and a 0% risk-free rate, so a validated result is a place to start looking, not a prediction.

Read the Tape

play it hard mode code

A trading game in one HTML file. Headlines hit, the price moves, and you decide: buy, sell, or stay flat.

One file No build No backend 60-second rounds

  • Every switch pays the spread, 2 basis points of the price, so reacting to every headline loses money on its own. Three modes change how often a headline is a fakeout, a dud, or a real move that quietly reverses with no news at all.
  • Scoring compares your P&L against perfect hindsight on the same price path: a trader who holds the true side of every move, is flat in between, and pays the same spread. That ratio becomes a rating from -5 to 5 stars.
  • Hard mode is the same idea with the training wheels off. You quote a bid and an ask into a live order book with price-time priority, against noise flow and an informed trader who sweeps your stale quote 150 ms after the headline unless you pull it first.

watersim

play it code

An interactive ASCII water simulator. C++17 for the terminal, ported to a single HTML file for the browser.

Zero dependencies ~30 FPS One write() per frame

  • A height field over two buffers. Each cell becomes half the sum of its neighbours minus its own last value, and that subtraction is what gives ripples momentum instead of letting them diffuse in place.
  • A moving boat is a moving wave source, so its wake bunches ahead and stretches behind. The Doppler effect came out of the physics; I didn't draw it in. Raw-mode termios gives the terminal build real mouse input, and each frame goes out in a single write(), so it never tears.
  • The browser build adds a double-slit preset: a wall with two openings and a plane wave on the left. The interference pattern is real, and it falls out of the same five-line update.
